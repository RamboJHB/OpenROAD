Plan C — 用 min-cut 一次选好所有 filler 的 VT

把「给每个 filler 选 VT」变成「给图上的点涂两种颜色」,最小割 = 违例最少的涂法。 一次全局求解,不迭代、不调 DRC。
STEP 0 · 例子

窗口:左 L cell、右 H cell、中间 3 个可改 filler

ωMS = 1(异 VT 不得相邻)。要给 f1 f2 f3 各选一个 VT(L 或 H), 使 MS 违例最少。大写 = 固定 cell,小写问号 = 待定 filler。

列:   0   1   2   3   4
      L   f1  f2  f3  H        L=cell(固定)  H=cell(固定)
          ?   ?   ?            f1..f3 待选 VT

直觉:左边想往 L 靠、右边想往 H 靠,中间必然有一处 L↔H 边界 → 至少 1 个 MS。 问题是把这个边界放在哪最省。

STEP 1 · 建图

节点 + 两个端点 S / T

每个 filler = 一个节点;S = 选 L,T = 选 H。 边 = 代价(违例):

· 端点边:f1 紧挨 L cell → 强连 S(它很想当 L); f3 紧挨 H cell → 强连 T。
· 相邻边:相邻 filler 之间连 cap=1 的边 = 「颜色不同就 +1 个 MS」。

  T(["T = 选 H"])
  S -- "强(贴 L cell)" --> f1["f1"]
  f1 -- "cap 1" --> f2["f2"]
  f2 -- "cap 1" --> f3["f3"]
  f3 -- "强(贴 H cell)" --> T

  classDef t fill:#fee2e2,stroke:#dc2626;
  classDef f fill:#fef3c7,stroke:#d97706;
  class S s
  class T t
  class f1,f2,f3 f

「强」= 容量很大(几乎不会去割它):意味着 f1 基本一定当 L、f3 基本一定当 H。

STEP 2 · 什么是「割」

要把 S 和 T 切断,割掉的边权之和 = 这套涂色的总违例

一个「割」= 切掉一组边,使 S 再也走不到 T。切完图分成两半:连着 S 的点 = 涂 L, 连着 T 的点 = 涂 H。

· 割掉一条 相邻边(cap 1)= 这两个相邻 filler 被分成不同色 → 付 1 个 MS。
· 割掉一条 端点强边 = 让某 filler 违背它旁边的 cell → 付很大代价(不划算)。

从 S 到 T 只有一条链:S → f1 → f2 → f3 → T。要断开它, 必须在链上割至少一条边。候选:两端的「强边」(贵)或中间两条 cap 1 边(便宜)。

STEP 3 · 求最小割

最便宜的割 = 割中间一条 cap=1 的相邻边

割 f2 — f3(代价 1)即可断开 S↔T,这是最省的。 (割 f1–f2 也是代价 1,平手时任选;端点强边太贵不选。)

  T(["T = 选 H"])
  S -- "强" --> f1["f1"]
  f1 -- "cap 1" --> f2["f2"]
  f2 -. "✂ 割这里 cap 1" .-> f3["f3"]
  f3 -- "强" --> T

最小割由 max-flow(最大流)算法精确求出,多项式时间,不用枚举所有涂法。 这里最小割 = 1 = 最少违例(L、H 两个 cell 夹着,必然有 1 处边界)。

割掉 f2–f3 后:f1、f2 还连着 S → 涂 L;f3 连着 T → 涂 H。

STEP 5 · 落地

映射回 VT,一次 apply

把每段同色的 filler run 用库 master exactFill 精确平铺 → clearSite 删旧 + placeFiller 建新。铺不出某段 → 该段 mark unfixable。

修前:  L   f1  f2  f3  H
修后:  L   L   L   H   H      ← f1f2=L 接左 cell,f3=H 接右 cell
              └ 唯一残留 MS 在 f2|f3,已是最优(L、H 夹着无法为 0)

残留的这 1 个 MS 是下限(两个异 VT cell 夹着,VT 替换消不掉)→ 如实 mark 并回报上游。min-cut 保证把它放在代价最小处。

为什么用 min-cut

对比 Plan A / B

· Plan A(边界贴合):靠规则手工决定拆分点;简单但复杂布局会过早判 unfixable。
· Plan B(窗口枚举/DP):窗内最优,但行数多时状态爆炸。
· Plan C(min-cut):把整片连通区域一次全局最优解出来, 两种 VT 时是精确解且快(max-flow 多项式),大簇也不怕。

超过两种 VT → α-expansion:每次挑一种 VT α,问每个 filler「保持现状 vs 改成 α」 (又是一次两色 min-cut),把所有 α 轮一遍直到不再改善 → 强近似全局最优。

局限:MW(宽度类)代价不如 MS(相邻类)那么自然地塞进边里,需用「相邻吸引 + 窄段惩罚」 近似;这点上 Plan B 直接数 MW 更准。实践:二态大簇用 C,其余用 A+B。
