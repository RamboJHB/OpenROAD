② 主流程 FillerVtRepair::repair(grid)

filler site = 可变 VT、cell site = 固定边界;贪心选 VT 使 2D 的 MW/MS 违例最少,再替换落地。

  C --> D["贪心坐标下降 每个 filler site 试遍库 VT"]

③ MW/MS 评估器 countViolations(site 网格模型)

每个被占用 site 带一个 VT;只看 site 网格,不是多边形 DRC。

  S --> VW["量同VT 垂直 run 长度"]
  HW --> MW{"水平 run 与垂直 run 都 短于 ωMW?"}
  VW --> MW
  MW -- 是 --> MWv["MW +1 窄颈 例如 1 宽跨行台阶"]

  MS -- 是 --> MSv["MS +1 异 implant 区相邻 当 ωMS≥1"]
  MS -- 否 --> OK2["MS 通过"]
  MWv --> SUM["总违例 = MW + MS"]
  MSv --> SUM
